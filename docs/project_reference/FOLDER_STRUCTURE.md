# Folder Structure\n- `lib/` - Main source code.\n  - `core/` - Routing (GoRouter), Theme, and Utilities.\n  - `models/` - Data models (e.g., UserModel, AppointmentModel).\n  - `providers/` - Riverpod providers for state management.\n  - `repositories/` - Data access layer.\n  - `screens/` - UI screens separated by roles (admin, patient, reception, shared).\n  - `widgets/` - Reusable UI components.\n
