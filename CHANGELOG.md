# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-16
### Added
- Complete Patient Portal (Registration, Login, Profile, Notifications).
- Complete Reception Dashboard (Queue Management, Walk-in Registration, Search).
- Complete Admin Dashboard (Doctor Management, Employee Management, Settings).
- Firebase Authentication via Phone OTP.
- Firestore integration for real-time data sync.
- Firebase Storage for profile images and medical records.
- Firebase Cloud Messaging for push notifications.
- Live Queue functionality.
- Responsive layout for web.
- Offline support capabilities.

### Fixed
- Fixed authentication state bug during OTP verification.
