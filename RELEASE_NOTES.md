# Release Notes - v1.0.0

**Release Date:** 2026-07-16

We are excited to announce the v1.0.0 release of the Dr. Baijus Clinic Management System.

## Highlights
- **Patient Journey Fully Digitized:** Patients can now register, book tokens, view their live queue status, and see appointment history directly from the app.
- **Reception Optimization:** Receptionists have a dedicated dashboard to handle walk-ins, track queue status in real-time, and call the next patient.
- **Administrative Control:** Admins can manage doctors, view detailed reports, and manage holidays from a centralized dashboard.

## Known Limitations
- Offline support is limited to read-only data caching. Modifications made offline will fail rather than queueing.
- Integration tests are currently missing and slated for v1.1.0.

## Supported Platforms
- Android (via App Bundle)
- Web (Responsive interface)
